# Покажи и скажи

Развивающая игра для малышей 3–5 лет, которые только начинают говорить: слова, понимание речи, слух, подражание, счёт, движение и рисование.

## Структура

```
index.html              главная страница: подключает стили и скрипты
manifest.webmanifest    название и иконка для «На экран Домой»
sw.js                   работа без интернета (создаётся tools/build.py)
css/style.css           все стили
js/images.js            список картинок: какой эмодзи/предмет → какой файл
js/core/                общие части: данные и слова, звук и голос, экраны,
                        микрофон, уровни, словарик, таймер, раскладка
js/games/               игры: рисование, «Подуй», «Попугай учит», «Говорим»,
                        «Кто это?» и «Сделай как я», картинки, счёт, коврик
js/main.js              кнопки, жесты и запуск игры
assets/img/             картинки (webp/png), список — assets/img/index.json
assets/icons/           иконки приложения
assets/audio/           место для будущей озвучки (p0001.mp3 и т.д.)
tools/build.py          обновляет sw.js и собирает игру в один файл dist/
tools/script-order.json порядок подключения скриптов (важен!)
tools/export-phrases.js выгрузка всех фраз игры (запускается в браузере)
tools/make_phrases_xlsx.py  таблица фраз для озвучки
```

Скрипты подключаются обычными `<script>` по порядку из `tools/script-order.json`. Если добавляете новый файл, впишите его туда и в `index.html` в нужное место.

## Как запустить на компьютере

```
python3 -m http.server 8000
```
и откройте http://localhost:8000 в браузере.

## Как обновить игру на GitHub Pages

1. После любых изменений запустите `python3 tools/build.py` — он обновит `sw.js`, чтобы iPad увидел новую версию.
2. Загрузите в репозиторий все файлы и папки (кроме `dist/`, она не нужна на сайте).
3. Прогресс, записи голоса и фото на устройствах сохраняются: они лежат на самом iPad, а не в репозитории.

## Как заменить картинку

Положите новый файл в `assets/img/` (лучше PNG или WebP с прозрачным фоном, от 512 px) и поменяйте путь в `js/images.js`, либо просто замените файл с тем же именем.
