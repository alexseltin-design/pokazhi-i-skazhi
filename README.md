# Покажи и скажи

Развивающая игра для малыша: «Нажимай и слушай», «Найди картинку», «Повтори за мной», «Рисуем пальцем», «Считаем», «Прыгай на цвет».

Открывать в Safari на iPad, затем «Поделиться» → «На экран «Домой»».
Фото семьи и записи голоса хранятся только на устройстве и в этот репозиторий не попадают.
